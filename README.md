# bayda-legal

Redirects only (since 25 Nov 2026). Builds 190 and older, and App Store Connect, link to
https://baydalabs.github.io/bayda-legal/, /terms-of-use.html and /support.html. Each now forwards to the
current page on bayda-app.com (/privacy/, /terms/, /support/), so nobody reads a stale copy.

The documents themselves are published from the Bayda app repo (`legal/`, via `scripts/publish-site.sh`).
Do not put a document back here.
